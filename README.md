## 数据集摘要![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/b3f7274952b54300adcf7a4ebbefeab9.png)

本数据集为高尔夫球场遥感影像语义分割数据集，包含1123张高清遥感图片，合计17000余像素级标注，覆盖沙坑、果岭、球道、发球台、水域5类高尔夫球场核心地物。遥感拍摄视角，地物边界清晰，适合做遥感地物分割、球场要素提取模型训练。

## 应用价值
1. 高尔夫球场数字化测绘、场地要素自动提取与地图矢量化
2. 遥感语义分割、地物分类算法训练、论文实验
3. 球场运维、场地面积统计、规划设计、景观监测
4. 低空遥感、国土自然资源遥感解译相关研究
